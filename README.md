# Comic TV · atualizações

Canal oficial de APKs e informações de atualização do Comic TV.

[Baixar a versão mais recente](https://github.com/wlmb091/comic-tv-updates/releases/latest)

Este repositório contém a infraestrutura do canal, sem o código-fonte do aplicativo. Nas releases, baixe o arquivo **Comic-TV-versão.apk**; os arquivos automáticos “Source code” são apenas deste canal.

O app confere tamanho, SHA-256, identidade, versão, compatibilidade e assinatura antes de oferecer o APK ao instalador do Android. A instalação depende da confirmação do usuário. Biblioteca, progresso e arquivos são preservados por atualização normal.

A geração e assinatura acontecem após os testes no repositório privado. Este canal recebe apenas APK e update.json em uma branch temporária; verifica o certificado e publica uma release inicialmente em rascunho, tornando-a disponível somente após subir os dois arquivos. A chave privada de assinatura não é armazenada aqui. Releases publicadas não são substituídas.
